# Security

## Reporting a vulnerability

If you believe you have found a security vulnerability in this project, please report it responsibly:

- **Preferred:** If you use GitHub, use [Security Advisories](https://docs.github.com/code-security/security-advisories) for the repository where this code is hosted.
- **Alternative:** Open a private or low-detail issue asking maintainers to contact you, without posting exploit details in public.

Include enough information to reproduce the issue (versions, configuration shape—**not** secrets).

## Scope

- Issues caused by Discord’s own APIs or clients should be reported to [Discord](https://discord.com/developers/docs/intro) through their channels.
- Do not share bot tokens, OAuth secrets, or other credentials in issues or pull requests.
